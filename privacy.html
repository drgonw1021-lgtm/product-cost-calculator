隐私政策

更新日期 2026-11-16 · 版本 v1.0 · 适用：落地页、领码页、免费网页版、Windows 桌面版

一句话：报价数据不出你的电脑；免费网页版不传模型；只有「领激活码」这一步会把机器码和一次访问记录发到服务器，因为它必须在服务器上算码。没有广告画像，没有出卖数据，没有追踪像素——除了 Cloudflare 那个不用 cookie 的访问计数。

一、这一页管什么

本政策适用于以下四处，它们的处理方式不一样，下面分开写清楚：

  • 落地页（product-cost-calculator.pages.dev）：看介绍、看价格、点下载。
  • 领码页（同一站点的 /claim）：填兑换券和机器码，换激活码。
  • 免费网页版（/web/）：拖 STEP 进去，只算塑料件材料费。
  • Windows 桌面版：装在你电脑上的 ProductCost.exe。

二、我们收什么、为什么收

在哪收什么为什么存在哪里
落地页 页面浏览、来源域名、粗略地区（国家/省级）、浏览器与系统的大类。 知道有没有人看、从哪来、哪一页留不住人。 Cloudflare Web Analytics。不用 cookie、不做设备指纹，只出汇总数，我们看不到单个访客。
领码页 兑换券号或订单号、机器码、算出来的激活码、领取时间、IP 地址、浏览器 User-Agent。 算激活码必须在服务器上做；IP 与时间用来拦批量薅羊毛（同一 IP 十分钟超过 12 次会被限流），也用来在你要换机、重装时帮你查回原来的码。 Cloudflare D1 数据库，只有我们能读。
免费网页版 什么都不发。你拖进去的 STEP 文件在你自己的浏览器里解析（WebAssembly 版 OpenCASCADE），没有上传接口。 — 只在你本机内存里，关掉页面就没了。
桌面版 报价数据、零件、BOM、方案对比：全部只在本机。 — 你选择的保存文件（.pquote / Excel），我们碰不到。
桌面版 · 授权 机器码、激活码、到期日。 每次启动在本地重算一遍校验，不需要联网。 %LOCALAPPDATA%\ProductCost\activate.dat；试用记录另存一份影子副本（%APPDATA% 与注册表 HKCU\Software\ProductCost），防止删文件重置试用。
邮件、微信 你主动写来的内容：邮箱、称呼、发票信息、问题描述。 回你、开票、排错。 QQ 邮箱。你不要求删除就留着，方便下次对得上。

三、桌面版只有三处会联网

软件是离线的。明确列出来，免得你担心它在后台偷偷做什么：

  • 实时汇率：向 open.er-api.com 请求币种汇率表，只带币种代码，不带你的任何数据。汇率结果会缓存到本机，一天内不重复请求。
  • 材料参考价：向 100ppi.com 取公开的原料价格页面。只发页码，不发你的零件或报价。
  • AI 助手：只有你自己在设置里填了 API Key 才会工作。没填就完全不联网。填了以后，你发给它的文字会送到你指定的那个服务商（默认 DeepSeek），去哪个地址、用哪个模型都由你决定。

四、我们不做什么

  • 不出卖、出租、交换任何数据。
  • 不做广告画像，不接第三方广告或追踪脚本。
  • 不收集通讯录、短信、相册、精确位置、键盘记录。
  • 不读你的文件。唯一一次读剪贴板，是你自己点「从剪贴板粘贴机器码」那一下。
  • 不上传你的 STEP、BOM、报价表——桌面版和网页版都没有这个能力。

五、机器码是什么

机器码是把「系统安装 GUID + 系统盘序列号 + CPU 型号」拼起来做一次 SHA-256 摘要，再转成 20 位字符（形如 XXXXX-XXXXX-XXXXX-XXXXX）。它不可逆——从这 20 位推不回你的 GUID 或序列号，也不含文件名、用户名、路径。它的用途只有一个：让一个激活码只能在一台机器上生效。

六、留多久

  • 订单与领码记录：保留到你不需要售后为止（换机、重装、重发码都要靠它）。你随时可以要求删除，删除后我们无法再帮你找回或补发激活码。
  • 访问统计：Cloudflare 侧只保留汇总计数，不保存个人级明细。
  • 邮件往来：保留到你要求删除。

七、你的权利

查询、更正、删除、导出——写邮件到 871756851@qq.com，说明你要处理的邮箱或订单号即可，7 个工作日内回复。删掉记录后，那张激活码在系统里就查不到了，但不影响已经激活的软件继续用。

八、第三方

  • Cloudflare：托管站点与数据库、访问统计。
  • 支付渠道：你选的那家（发卡平台 / 虎皮椒 / Paddle 等）。付款信息在他们那边，我们只收到「已付款、金额、订单号」，拿不到你的卡号。
  • QQ 邮箱：收发邮件。
  • AI 服务商：只有你自己配了 Key 才会涉及。

九、数据在境外

Cloudflare 的节点遍布全球，你提交的领码记录可能被存到中国大陆以外的机房。付款信息由支付渠道按其所在地的规则处理。

十、未成年人

这是给工厂、贸易公司、设计公司的成本核算工具，不面向 14 岁以下的孩子，我们也不会主动收集他们的信息。

Privacy Policy

Updated 2026-11-16 · v1.0 · Covers: landing site, claim page, free web app, Windows desktop app

In one line: your costing data never leaves your machine; the free web app never uploads a model; only the “claim activation code” step sends a machine code and one access record to a server, because the code has to be computed there. No ad profiling, no selling data, no tracking pixels — apart from Cloudflare’s cookie-free visit counter.

1. What this policy covers

Four places, each handled differently:

  • Landing site (product-cost-calculator.pages.dev): read the intro, check the price, download.
  • Claim page (/claim on the same site): enter a voucher and machine code, get the activation code.
  • Free web app (/web/): drop in a STEP file, get plastic-part material cost.
  • Windows desktop app: ProductCost.exe, installed on your own PC.

3. The desktop app goes online in exactly three places

The software is offline. Listed explicitly so you do not have to wonder:

  • Live FX rates: requests a CNY rate table from open.er-api.com. Currency codes only, none of your data. Rates are cached locally; no repeat requests within a day.
  • Material reference prices: fetches a public raw-material price page from 100ppi.com. Page numbers only — never your parts or quotes.
  • AI assistant: works only if you enter an API key yourself. Without a key it never goes online. With one, the text you send goes to the provider you configured (DeepSeek by default); the endpoint and model are your choice.

4. What we never do

  • Never sell, rent, or trade data.
  • No ad profiling, no third-party ad or tracking scripts.
  • No contacts, SMS, photos, precise location, or keystroke logging.
  • We do not read your files. The single clipboard read happens when you click “paste machine code” yourself.
  • We never upload your STEP, BOM, or quote sheet — neither the desktop nor the web app can do it.

5. What a machine code is

The machine code joins the OS installation GUID, the system volume serial number, and the CPU model, runs one SHA-256 digest, and renders 20 characters (like XXXXX-XXXXX-XXXXX-XXXXX). It is one-way: those 20 characters cannot be turned back into your GUID or serial, and contain no file name, user name, or path. Its only job is to bind one activation code to one machine.

6. How long we keep it

  • Order and claim records: until you no longer need support (machine change, reinstall, code reissue all depend on them). You can ask us to delete them at any time — after which we can no longer recover or reissue your activation code.
  • Visit statistics: aggregate counts only on the Cloudflare side, no per-visitor detail.
  • Email threads: until you ask us to delete them.

7. Your rights

Access, correct, delete, export — email 871756851@qq.com with the address or order number to act on, and we reply within 7 business days. Deleting a record removes that activation code from our system, but does not stop software that is already activated from running.

8. Third parties

  • Cloudflare: hosting, database, visit analytics.
  • Payment channel: whichever you pick (a card-key marketplace, Xunhupay, Paddle, …). Payment details stay with them; we receive only “paid, amount, order number” — never your card number.
  • QQ Mail: sending and receiving email.
  • AI provider: only if you configure a key yourself.

9. Data outside mainland China

Cloudflare operates globally, so a claim record you submit may be stored in a data centre outside mainland China. Payment details are handled by the payment channel under its own jurisdiction’s rules.

10. Minors

This is a costing tool for factories, trading companies, and design studios. It is not aimed at children under 14, and we do not knowingly collect their information.
